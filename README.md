# Deep-Learning-Labs

This repository contains my lab assignments for the **Deep Learning** course at Imam Abdulrahman Bin Faisal University.

## Topics Covered

The course covers the following topics:

* **Introduction to Deep Learning**

  * History, motivations, and applications of Deep Learning
  * Neural network architectures and terminology

* **Neural Networks**

  * Activation functions
  * Feedforward neural networks
  * Gradient-based optimization
  * Backpropagation

* **Neural Network Architectures**

  * Convolutional Neural Networks (CNNs)
  * Transfer learning
  * Fine-tuning pre-trained models
  * Recurrent Neural Networks (RNNs)
  * Long Short-Term Memory (LSTM)
  * Gated Recurrent Units (GRUs)

* **Optimization**

  * Stochastic Gradient Descent (SGD)
  * Mini-batch SGD
  * Adam
  * RMSProp
  * Learning rate methods

* **Regularization and Training Techniques**

  * Dropout
  * L1 and L2 regularization
  * Batch normalization
  * Weight initialization

* **Deep Learning Frameworks**

  * TensorFlow
  * PyTorch
  * Neural network training and debugging
  * Hyperparameter tuning
  * Training visualization

* **Advanced Architectures and Techniques**

  * Autoencoders
  * Dimensionality reduction
  * Multimodal learning
  * Multitask learning
  * Attention mechanisms
  * Neural Architecture Search (NAS)

* **Generative Models**

  * Autoregressive models
  * Text generation
  * Variational Autoencoders (VAEs)
  * Generative Adversarial Networks (GANs)

* **Ethical and Social Considerations**

  * Bias and fairness in Deep Learning
  * Ethical AI decision-making
  * Privacy and security
  * Regulation and responsible AI development

* **Special Topics**

  * Reinforcement learning
  * Deep Learning and reinforcement learning
  * Emerging trends and future directions

## Repository Structure

Each lab is organized separately and includes the relevant code notebooks, datasets (when applicable), and supporting files.
